✅ Split Read Path: Decouples request and response for better timing
✅ Proper CDC: Uses 2-flop synchronizers for control signals
✅ Correct Enable Logic: FIFO read/write enables based on FSM and status
✅ Write Completion Handshake: Via synchronized FIFO status signal
